# Hostoryx

A no-subscription operations and profitability command center for independent short-term rental hosts and small property portfolios.

**Live site:** https://attiabadawy3-eng.github.io/hostoryx/  
**Free STR profit calculator:** https://attiabadawy3-eng.github.io/hostoryx/free-calculator.html  
**Custom setup service on Upwork:** https://www.upwork.com/services/product/development-it-a-professional-excel-dashboard-with-automated-kpi-reporting-2103598123436181157?ref=project_share

## What Hostoryx is built to track

- Multi-property bookings and occupied nights
- Arrivals, departures and cleaning turnovers
- Gross revenue, channel fees and net income
- Occupancy, ADR and RevPAR
- Expenses, maintenance and inventory
- Break-even occupancy and target nightly rate
- Owner reporting and reusable guest message templates
- CSV imports and portable JSON backups
